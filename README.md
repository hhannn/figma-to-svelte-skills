# Figma to Svelte skills

Two skills for building responsive SvelteKit sections from Figma:

- `figma-to-svelte-sections`: reusable design-to-code workflow.
- `intergest-tailwind-mapping`: Intergest-specific Tailwind and component conventions.

Figma shaders are treated as placeholders. Use the base image and wire the shader later.

Install with `npx skills add hhannn/figma-to-svelte-skills` once this repository is published.
